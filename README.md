## Aesthetic Philosophy: *Highland Modernist*
This portfolio is crafted adhering strictly to the **AI Design Skills** design specifications (`landing-page-design` and `frontend-design`). It merges contemporary Swiss typography and dark-mode surface minimalism with the dignified cultural heritage of Tibet.

- **Identity Narrative:** *"A village with no country"* — turning the lived reality of refugee exile into resilient digital sovereignty, civic preservation, and borderless software architecture.
- **Color System:** Dark mode flat surface layers (`#000000`, `#131209`, `#181818`, `#1F1F1F`, `#272727`, `#313131`) with warm heritage gold (`#D4AF37`) and phosphor cyan (`#38BDF8`) accents. Zero background gradients.
- **Typography:** Geist + Geist Mono + Noto Sans Tibetan. Strict type scale snapped to Tailwind steps. No italics. No ultra-bold (900).
- **Motion:** Decelerating cubic-bezier curves (`cubic-bezier(0.22, 1, 0.36, 1)`), layout shifts at 500ms, color shifts at 300ms, respecting `prefers-reduced-motion`.
- **Mandatory B11 Scroll Tagline Reveal:** Words illuminate individually as the visitor scrolls down.
- **Design Spells Interactive Feature:** Live in-browser **Tibetan Typing Tutor & Keyboard Sandbox**, allowing visitors to type Tibetan syllables directly on screen or via physical keyboard.

## Local Preview & Deployment

### Instant Preview
Double-click `index.html` to open directly in any browser, or run a local static server:

```bash
# Python 3
python3 -m http.server 3000

# or Node.js npx serve
npx serve .
```

Then visit `http://localhost:3000`.

### Deploying to GitHub Pages
1. Push this folder to your repository: `https://github.com/tenzin67/tenzin67.github.io` (or a `portfolio` repo).
2. In GitHub Settings → Pages, select the `main` branch root `/`.
3. The site goes live immediately with custom favicon, OpenGraph cards, and 404 handler!
